# Generic
- 코드의 재사용성과 형식 안전성을 높이기 위해 데이터 타입을 일반화하는 강력한 기능.
- 여러 데이터 형식에 대해 동일한 로직에 적용해야 할 때, 컬렉션 타입에서 다양한 데이터 형식을 저장하고 관리해야 할 때, 데이터 형식에 따라 다른 연산을 수행해야 할 때 사용한다.
- 제네릭을 사용해 특정 데이터 타입에 의존하지 않아 유연하게 사용할 수 있는 클래스, 메서드, 인터페이스 생성 가능.
>Generic 사용법 예시
```csharp
class Utility
{
    public static void Print<T>(T data) //T는 매개변수로 클래스가 생성될 때 타입 결정
    {
        Console.WriteLine($"데이터: {data}");
    }
}

class Program
{
    static void Main()
    {
        Utility.Print(123); // 정수 출력
        Utility.Print("Hello"); // 문자열 출력
        Utility.Print(45.67); // 실수 출력
    }
}
```
- 제네릭을 이용한 [박싱](Boxing.md)과 [언박싱](UnBoxing.md) 방지 효과
    - 박싱과 언박싱 기능은 최적화에 유용하지만, 박싱과 언박싱을 너무 많이 사용해 object에 너무 많이 넣다 뺐다 할 경우 힙 메모리 할당과 GC의 성능 비용이 발생하기 때문에 박싱과 언박싱을 남용하는 것은 권장되지 않는다.
    - 하지만 제네릭을 사용하면 object에 접근할 필요 없이 유연하게 다양한 타입을 저장할 수 있기 때문에 부담이 덜해진다.
