# Polymorphism(다형성)
- 객체 지향 프로그래밍의 핵심 개념으로, 하나의 객체가 여러 가지 타입이나 형태를 가질 수 있는 성질, 하위 개념으로 가상화와 추상화를 지님.
- 가상화(virtual)
    - 몸체가 있는 부모 함수를 자식 클래스에서 필요에 따라 재정의(override)하는 것. virtual 키워드를 사용한다.
    - 동적 할당에서만 가능.
- 추상화(abstract)
    - 몸체가 없는 부모 함수를 자식 클래스에서 무조건 자식 클래스에서 재정의(override)하는 것. abstract 키워드를 사용한다.
    - 마찬가지로 동적 할당에서만 가능.
- 추상 클래스
    - 객체 지향 프로그래밍에서 미완성 설계도와 같은 역할을 하는 클래스. 추상 메소드를 하나 이상 포함한 클래스를 말한다.

- Overriding
    - 다형성에서 자식 클래스에서 사용할 수 있는 재정의 기능으로, override 키워드를 통해 부모 클래스에 있는 기능을 이어받아 재정의하는 역할을 맡는다.
    - 재정의하지 않아도 new 키워드를 사용해 부모 클래스의 함수와 이름은 똑같이 쓸 수 있지만, 이 경우는 별개의 클래스 내의 별개의 함수로 인정되어 부모 클래스의 기능을 덮어씌우기 때문에 부모 클래스의 것과의 연관이 없어진다.
    - 따라서 부모 클래스로의 업캐스팅을 했을 경우 override 없이 자식 클래스에 만들어진 함수는 부모 클래스의 것으로 덮어씌워진다.
