# Class
- 객체 지향 프로그래밍의 핵심
- 각 클래스는 클래스 이름과 똑같으며 리턴형을 가지지 않는 생성자를 가지고 있음
>클래스의 생성자
```csharp
class Program
{
	public Program()
	{

	}
}
```
- 클래스는 기본적으로 생성자가 이미 선언되었기 때문에 파라미터에 아무 것도 입력하지 않은 기본 생성자만 사용할 경우 생성자를 따로 선언할 필요가 없음
>클래스의 생성자 선언 조건
```csharp
class Program
{
	public Program()
	{

	}

	public Program(string text)
	{

	}
}
```
- 하지만 파라미터를 가지는 생성자를 선언할 경우 기본 생성자의 무언 선언이 더 이상 인정되지 않기 때문에 반드시 기본 생성자를 선언해주어야 함.
