# Property
- 클래스 내부의 필드 값을 외부에서 접근할 수 있도록 하면서 캡슐화를 지원하는 객체지향 프로그래밍의 한 요소이다.
- [public](../AccessModifier/pubilc.md)을 통해 변수를 외부에 공개하는 것은 가능하지만, 변수를 외부에 공개한다는 것은 객체 자체에 영향을 끼칠 수도 있다는 것이기 때문에 권장되지 않는다.
- 따라서 [private](../AccessModifier/private.md)의 캡슐화를 지원하면서도 안전하게 외부에서 값을 읽어들일 수 있도록 지원하는 기능이라 할 수 있다.
- 프로퍼티의 기능은 [get](get.md)과 [set](set.md)으로 나뉜다.
