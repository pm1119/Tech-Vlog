# Diagram
- 개발에 앞서 작성하는 일종의 프로그램 설계도
- 유즈케이스 다이어그램
    - 유즈케이스 다이어그램은 사용자, 그리고 사용자가 수반한 다른 유스 케이스 간의 관계를 보여주는 사용자-시스템 간 상호작용의 표현. 유즈케이스 다이어그램은 각기 다른 종류의 시스템 사용자와 각기 다른 유스 케이스를 식별할 수 있으며 다른 유형의 다이어그램이 수반되기도 함
- 클래스 다이어그램
    - 구조 다이어그램으로 클래스 내부 구성요소 및 클래스 간의 관계를 도식화하여 시스템의 특정 모듈이나 일부 및 전체를 구조화함. 개발하기 전, 클래스 다이어그램을 그리게 되면 시스템 내 클래스 간의 의존성 파악과 팀원들 간 의사소통이 편리함.
- 시퀀스 다이어그램
    - 시계열(시간 순서)로 정렬된 객체 상호작용을 보여주는 것. 시나리오 기능을 수행하는데 필수적인 객체들 간에 교환되는 일련의 메시지들과 시나리오에 수반되는 객체와 클래스를 표현함. 시퀀스 다이어그램은 일반적으로 개발 중인 시스템의 논리적 뷰의 유즈 케이스 실현화와 관련됨.
