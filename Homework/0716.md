# 0716_Homework
- 과제에서 사용하게 될 기능들
    - 변수, 배열, 함수 : 데이터 저장과 처리
    - 조건문과 반복문 : 게임 메뉴, 입력 유효성 검사, 전투 루프
    - 클래스, 상속, 다형성 : 캐릭터 및 구조 등의 객체지향 설계
    - List, Directory : 아이템 목록, 인벤토리 등의 제네릭 컨테이너 관리
- 1단계 구현
    - 캐릭터 생성 화면
        - 구현해야 할 항목
            - Player 클래스 
                - string name
                - float hp, mp
                - float attack, defence
            - string 타입으로 이름 입력
            - string 타입으로 hp, mp 입력 받기
                - ","로 문자열 배열 분할해서 hp, mp 저장
            - string 타입으로 attack, defence 입력 받기
                - ","로 문자열 배열 분할해서 attack, defence 저장 
            - 저장 결과 보여주기 - PM의 상태창 보여주기
- 2단계 구현
    - 입력 검증 화면
        - 1단계에서 입력받을 때 값 검증
            - name의 Length가 3 이하일 때 다시 입력
            - hp < 50, mp < 40이면 다시 입력
            - 입력 블럭을 while(true)로 감싸기
            - 조건을 만족하면 break로 입력 루프 탈출
            - 상태창 보여주기
- 3단계 구현
    - 상태 관리 메뉴
    - HP 포션 3개, MP 포션 3개를 지급했습니다.
    - 1번 : HP UP, 2번 : MP UP, 3번 : 공격력 2배, 4번 : 방어력 2배, 5번 : 능력치 보기, 6번 : 게임 시작
    - HP 포션, MP 포션 변수에 저장
    - 공격력 Up 쿠폰, 방어력 Up 쿠폰 변수에 저장
    - bool bGameStart = false => 게임이 시작되었는지 판단할 변수
    - while(bGameStart == false) + switch(select)로 메뉴 루프 구현
    - HP 포션, MP 포션, 공격력 Up 쿠폰, 방어력 Up 쿠폰 각각 0이면 사용 불가
            - 포션이 부족합니다.
            - 쿠폰이 부족합니다.
    - 0번이 입력되면 게임 시작
        - bGameStart = true
