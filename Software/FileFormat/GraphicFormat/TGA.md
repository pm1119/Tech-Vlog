# TGA
- 이미지 데이터 손실이 없는 완전 무손실 비압축 포맷으로, 게임 그래픽 디자인이나 3D 텍스처 작업, 비디오 편집 등에 주로 사용됨.
- 장점
    - 색상 왜곡이 없는 무손실 이미지 저장 가능. 배경이 투명한 알파 채널을 RGB 채널과 독립적으로 제어하기 용이하며 포토샵, GIMP, Paint.NET 등 대부분의 이미지 편집 프로그램에서 열고 편집할 수 있어 호환성이 뛰어남.
- 단점
    - 압축하지 않기 때문에 용량이 크며, 16비트 색상은 지원하지 않아 포토샵에서 저장되지 않는다면 이미지 모드가 8비트(8Bit)로 설정되어 있는지 확인해야 함.
