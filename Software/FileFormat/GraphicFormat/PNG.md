# PNG(Portable Network Graphics)
-  이미지의 품질을 원본 그대로 유지하면서 파일 용량을 줄이는 무손실 압축 방식의 그림 파일 형식
- 장점
    - 배경을 투명하게 처리할 수 있어 겹쳐서 배치하거나 특정 사물만 깔끔하게 따서 쓸 때 매우 유용함.
    - 이미지를 압축하거나 저장해도 원본의 품질이 저하되지 않아 글씨나 선이 선명하게 유지됨
    - 기존의 GIF 형식이 가진 256색 한계를 극복하여 수백만 가지의 트루 컬러를 세밀하게 표현할 수 있음
- 단점
    - 원본 데이터를 모두 보존하기 때문에 사진처럼 복잡한 이미지는 JPG 등 다른 형식보다 파일 크기가 커질 수 있음.
