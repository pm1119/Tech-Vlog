# File Dormat
- 컴퓨터 파일에 데이터를 저장하고 인코딩하는 방식
- 대표적인 파일 포맷
    - 문서: PDF, DOCX, HWP, TXT
    - 이미지: [JPG](FileFormat/GraphicFormat/JPG.md), PNG, GIF, WebP, [BMP](FileFormat/GraphicFormat/BMP.md), [TGA](FileFormat/GraphicFormat/TGA.md)
    - 영상: MP4, AVI, MKV, MOV
    - 음악: MP3, WAV, FLAC
    - 압축: ZIP, RAR, 7Z
