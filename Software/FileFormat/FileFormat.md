# File Format
- 컴퓨터 파일에 데이터를 저장하고 인코딩하는 방식
- 대표적인 파일 포맷
    - 문서: PDF, DOCX, HWP, TXT
    - 이미지: [JPG](./GraphicFormat/JPG.md), [PNG](./GraphicFormat/PNG.md), WebP, [BMP](./GraphicFormat/BMP.md), [TGA](./GraphicFormat/TGA.md)
    - 영상: MP4, [AVI](./VideoFormat/AVI.md), MKV, MOV
    - 음악: MP3, [WAV](./AudioFormat/Wav.md), FLAC
    - 압축: ZIP, RAR, 7Z
