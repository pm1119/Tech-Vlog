# ProcessMemory
- 코드 영역
    - 실행할 프로그램의 명령어(바이너리 코드)가 저장되는 공간. CPU가 이 영역에서 명령어를 가져와 처리하며, 변경을 막기 위해 읽기 전용으로 설정되어 있음.
- 데이터 영역
    - 프로그램의 실행과 함께 할당되며, 프로그램이 종료될 때까지 유지되는 전역 변수와 정적 변수가 저장되는 공간
- 힙 영역
    - 프로그램 실행 중(런타임) 크기가 결정되는 동적 메모리 할당 영역으로, 프로그래머가 직접 메모리를 할당하고 해제하며, 객체나 동적 배열 등 크기가 유동적인 데이터, 즉 값을 저장하는 영역.
- 스택 영역
    - 함수 호출 시 생성되는 지역 변수, 매개변수, 반환 주소 등 임시 데이터를 저장하는 메모리 공간으로, 흔히 데이터가 저장되는 주소, 즉 참조를 저장하는 곳이라고도 함.
