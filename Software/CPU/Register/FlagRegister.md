# Flag Register
- 플래그 
    - CPU의 연산장치인 ALU가 계산 결과값과 더불어 내보내는 정보. ALU의 연산 결과를 정확히 나타내기 위해 추가적인 정보를 내보낼 필요성이 있는데 이러한 연산 결과에 대한 추가적인 상태 정보를 가리킴.
    - 플래그의 종류
        - 부호 플래그
            - 연산한 결과의 부호를 나타내는 플래그.
            - 부호 플래그가 1일 경우 계산 결과는 음수, 0일 경우 양수를 나타냄.
        - 제로 플래그
            - 연산 결과가 0인지의 여부를 나타내는 플래그.
            - 제로 플래그가 1일 경우 연산 결과는 0이며, 0일 경우 0이 아님.
        - 캐리 플래그
            - 연산 결과 올림수나 빌림수가 발생했는지를 나타내는 플래그.
            - 캐리 플래그가 1일 경우 올림수나 빌림수가 발생, 0일 경우 발생하지 않았음을 나타냄.
        - 오버플로우 플래그
            - 오버플로우가 발생했는지를 나타내는 플래그.
            - 오버플로우 플래그가 1일 경우 오버플로우가 발생했으며, 0일 경우 발생하지 않았음을 나타냄.
        - 인터럽트 플래그
            - 인터럽트가 가능한지를 나타내는 플래그.
            - 인터럽트 플래그가 1일 경우 인터럽트가 가능하며, 0일 경우 불가능함을 나타냄.
        - 슈퍼바이저 플래그
            - 커널 모드로 실행 중인지, 사용자 모드로 실행 중인지 나타내는 플래그.
            - 슈퍼바이저 플래그가 1일 경우 커널 모드, 0일 경우 사용자 모드로 실행 중임을 나타냄.
- 이러한 플래그들을 ALU가 연산 결과와 함께 내보낼 때 내보낸 플래그를 저장하는 레지스터를 플래그 레지스터라고 함.
