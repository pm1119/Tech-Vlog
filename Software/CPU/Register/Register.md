# Register
- CPU 내부의 임시 저장 장치. 프로그램을 실행하는 데 필요한 데이터를 임시로 저장한다. 여러 개의 레지스터 종류가 있으며 각기 다른 이름과 역할을 가지고 있다.
- 종류
	- [프로그램 카운터(PC)](PC.md)
	- [명령어 레지스터(IR)](IR.md)
	- [누산기(Accumulator)](AC.md)
	- [메모리 주소 레지스터(MAR)](MAR.md)
	- [메모리 버퍼 레지스터(MBR)](MBR.md)
	- [범용 레지스터(GPR))](GPR.md)
	- [플래그 레지스터](FlagRegister.md)
