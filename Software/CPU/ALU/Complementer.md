# 보수기(Complementer)
- [ALU](ALU.md)에 속하는 핵심 회로 중 하나로, 뺄셈 연산을 수행할 수 있도록 입룍된 이진수 데이터를 1의 보수나 2의 보수 형태로 바꿔주는 역할을 함
    - 보수 
        - 어떤 수에 부족한 양을 채워주어 특정한 기준이 되는 수(진법의 밑수)를 만드는 수
        - 1의 보수: 이진수의 각 자릿수에서 0은 1로, 1은 0으로 전부 바꾼 수. (예: 1010의 1의 보수는 0101)
        - 2의 보수: 1의 보수 값에 1을 더한 수. 컴퓨터에서 음수를 나타낼 때 표준으로 쓰임. (예: 1010의 2의 보수는 0101 + 1 = 0110)
- 예를 들어, A - B 형태의 뺄셈을  A + (-B) 형태로 바꾸기 위해, 보수기가 B 값을 음수(보수) 형태로 변환하는 것.
- 0과 1을 뒤집는 NOT 연산 과정을 거쳐 보수를 생성할 수 있다.
