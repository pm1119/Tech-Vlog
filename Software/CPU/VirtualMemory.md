# VirtualMemory
- 가상 메모리 관리정책
    - 물리 메모리(RAM)의 한계를 극복하기 위해 운영체제가 보조기억장치와 데이터를 주고받는 방식을 제어하는 핵심 규칙
- 가상 메모리 페이징
    - 물리 메모리를 일정한 크기인 프레임으로 나누고, 논리 메모리를 프레임과 동일한 크기의 페이지로 나눔. 이후 필요한 페이지를 프레임에 적재하고 실행함. 각 페이지는 연속적이지 않은 공간에 존재할 수 있으며 각 프로세스는 각자의 페이지 테이블을 가짐
- 가상 메모리 세그멘테이션
    - 프로그램을 고정된 크기가 아닌 함수, 데이터, 스택 등 논리적 의미 단위(Segment)로 나누어 메모리에 적재하는 기법
- 가상 메모리 페이지드 세그멘테이션
    - 가상 메모리 관리에서 세그멘테이션의 논리적 보호 및 공유 기능과 페이징의 메모리 할당 효율성을 결합한 기법. 프로그램을 먼저 의미 단위의 세그먼트로 나누고, 각 세그먼트를 다시 고정된 크기의 페이지로 분할하여 주기억장치에 적재함.
- Trashing
    - 가상 메모리 시스템에서 페이지 부재가 과도하게 발생하여 프로세스가 실제 작업보다 페이징 작업에 더 많은 시간을 소비하는 현상. 시스템이 페이지를 메모리에 적재하고 교체하는 작업에만 몰두하여 CPU 이용률이 급격히 저하되고 시스템 응답 시간이 현저히 증가함. 다중 프로그래밍 환경에서 메모리 부족 시 발생하는 심각한 성능 저하 문제.
