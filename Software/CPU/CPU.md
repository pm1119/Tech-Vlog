# CPU
- 컴퓨터의 두뇌와도 같은 부품으로, 메모리에 저장된 명령어를 읽어들이고 실행하는 부품.
- 주요 부품
    - ALU(산술논리연산장치)
        - 컴퓨터 내부에서 수행되는 계산을 도맡아 수행하는 컴퓨터의 부품
    - [레지스터](Register/Register.md)
        - CPU 내부의 임시 저장 장치. 프로그램을 실행하는 데 필요한 데이터를 임시로 저장한다. 여러 개의 레지스터 종류가 있으며 각기 다른 이름과 역할을 가지고 있다.
    - 제어장치
        - 제어 신호를 ALU로 내보내고 명령어를 해석하는 부품.
        - 제어장치가 받아들이는 정보
            - 1. 클럭 신호
                - 클럭
                    - 컴퓨터의 모든 부품을 일사불란하게 움직일 수 있게 하는 시간 단위. 컴퓨터 내부에서 이뤄지는 모든 작업(ex. 레지스터 간 데이터 이동, ALU의 연산 수행 등)은 클럭의 주기에 맞춰 진행됨.
                    - 단, 모든 작동이 클럭 한 박자에만 움직이는 것은 아니며, 하나의 명령어가 여러 클럭에 걸쳐 실행되는 경우도 있음.
            - 2. 해석해야 할 명령어
                - CPU가 해석해야 할 명령어는 [명령어 레지스터](Register/IR.md)에 저장됨. 제어장치는 명령어 레지스터로부터 해석할 명령어를 받아들이고 해석한 뒤, 제어 신호를 발생시켜 컴퓨터 부품들에 수행해야 할 내용을 알려줌.
            - 3. [플래그 레지스터](Register/FlagRegister.md) 속 플래그 값
                - 제어장치가 제어 신호를 통해 컴퓨터 부품들을 제어하면서 플래그를 무시해서는 안 되므로, 플래그 값을 받아들이고 참고하여 제어 신호를 발생시킴
            - 4. [제어 버스](Bus.md)로 전달된 제어 신호
                - 제어 신호는 비단 CPU뿐만 아니라 입출력장치를 비롯한 CPU 외부 장치도 발생시킬 수 있음. 따라서 제어장치는 제어 버스를 통해 외부로부터 전달된 제어 신호를 받아들이기도 함.
        - 제어장치가 내보내는 정보
            - CPU 외부에 전달하는 제어 신호
                - CPU 외부 장치로부터 제어 신호를 받아들이는 것처럼 제어장치 또한 제어 버스를 통해 외부로 제어 신호를 보낼 수 있으며, 보통은 메모리와 입출력장치로 보냄.
                - 메모리나 입출력장치로 제어 신호를 보내 값을 읽거나 새로운 값을 쓸 수 있음
            - CPU 내부에 전달하는 제어 신호
                - 크게 ALU에 전달하는 제어 신호와 레지스터에 전달하는 제어 신호로 나뉘며, ALU에는 수행할 연산을 지시하기 위해, 레지스터에는 레지스터 간 데이터를 이동시키거나 레지스터에 저장된 명령어를 해석하기 위해 내보냄.
