# InstructionCycle
- 인출 사이클
    - 메모리에 저장된 명령어 하나를 실행해야 한다 했을 때, 메모리에 있는 명령어를 CPU로 가져오는 사이클
- 간접 사이클
    - 명령어를 인출해 CPU로 가져왔다 하더라도 바로 실행할 수 없는 경우, 명령어를 실행하기 위해 한번 더 메모리에 접근하는 사이클.
- 실행 사이클
    - CPU로 가져온 명령어를 실행하는 사이클. 제어장치가 명령어 레지스터에 담긴 명령어를 해석하고 제어 신호를 발생시킴.
- 인터럽트 사이클
    - 인터럽트 요청 신호를 받은 CPU가 작업을 백업하고 인터럽트 플래그를 통해 인터럽트를 받아들일 수 있는지 여부를 확인하고 인터럽트를 받아들일 수 있을 경우 인터럽트 벡터를 참조해 인터럽트 서비스 루틴을 실행, 끝날 경우 백업해 둔 작업을 복구하고 실행을 재개하는 사이클
    - 인터럽트
        - CPU가 꼭 주목해야 하거나 빨리 처리해야 할 다른 작업이 생겼을 때 기존 작업을 잠시 중단하도록 방해하는 신호
