# MemoryFragmentation
- 메모리 단편화 - 내부
    - 메모리를 할당할 때 프로세스가 필요한 양보다 더 큰 메모리가 할당되어 메모리 공간이 낭비되는 상황. 예를 들어 메모장을 틀었는데 OS가 10Kb 할당, 하지만 7kb만 사용하고 있을 때 필요 이상으로 프로세스가 메모리를 할당받았다면 내부 단편화 3kb만큼 생김.
- 메모리 단편화 - 외부
    - 남아있는 총 메모리 공간이 요청된 크기보다 크나, 공간들이 연속적이지 않고 조각나 있어 프로세스를 적재할 수 없는 현상. 주로 [세그멘테이션](VirtualMemory.md) 방식에서 발생함
- 메모리 단편화 - 압축
    - 메모리 공간을 재배치하여 단편화로 인해 분산되어 있는 메모리 공간들을 하나로 합치는 기법
- 메모리 단편화 - 메모리 풀
    - 필요한 크기 및 개수의 메모리 블록을 시스템으로부터 사전에 미리 할당(확보)해 두고, 프로그램이 필요할 때마다 이를 빌려주고 다 쓰면 반납받아 관리하는 기법
