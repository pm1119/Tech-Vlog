# CasheMemory
- 캐시 메모리 지역성:
        - 프로그램 실행 시 메모리에 균등하게 접근하지 않고, 특정 순간에 특정 데이터나 인접한 데이터를 집중적으로 참조하는 특성
- 캐시 메모리 일관성
    - 여러 로컬 캐시에 저장된 공유 리소스 데이터의 균일성을 의미함. 캐시 일관성 시스템에서 여러 클라이언트가 공유 메모리 리소스의 동일한 영역에 대한 캐시된 복사본을 가지고 있다면, 모든 복사본은 동일함.
- 캐시 메모리 매핑
    - 크기가 작은 캐시 메모리에 메인 메모리(RAM)의 데이터를 어떻게 배치할지 결정하는 방식
