# Register
- [프로그램 카운터(PC)](../Process/Thread/ThreadControlBlock.md)
    - 메모리에서 가져올 명령어의 주소, 즉 메모리에서 읽어 들일 명령어의 주소를 저장하는 레지스터. 프로그램 카운터를 명령어 포인터(Instruction Pointer)라고 부르는 CPU도 존재함.
- 명령어 레지스터(IR)
    - 해석할 명령어, 즉 방금 메모리에서 읽어 들인 명령어를 저장하는레지스터. 제어장치는 명령어 레지스터 속 명령어를 받아들이고 이를 해석한 뒤 제어 신호를 내보냄.
- AC(Accumulator)
    - 중앙처리장치(CPU)의 산술논리장치(ALU)에서 산술 및 논리 연산의 중간 결과물을 단기적으로 저장하는 특수 목적 레지스터
- 메모리 주소 레지스터(MAR)
    - 메모리의 주소를 저징하는 레지스터. CPU가 읽어들이고자 하는 주소 값을 주소 버스로 보낼 때 메모리 주소 레지스터를 거치게 됨.
- 메모리 버퍼 레지스터(MBR)
    - 메모리와 주고받을 값(데이터와 명령어)을 저장하는 레지스터. 즉, 메모리에 쓰고 싶은 값이나 메모리로부터 전달받은 값은 메모리 버퍼 레지스터를 거침. CPU가 주소 버스로 내보낼 값이 메모리 주소 레지스터를 거친다면, 데이터 버스로 주고받을 값은 메모리 버퍼 레지스터를 거침.
