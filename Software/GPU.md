# GPU
- 그래픽 카드라고도 불리며, 대규모 데이터를 여러 코어로 나누어 동시에 처리하는 병렬 연산 특화 프로세서.
- GPGPU
    - GPU의 범용 연산으로, CPU에서 처리하던 연산 작업을 GPU에서도 처리할 수 있게 해주는 것
- CPU vs GPU
    - CPU는 소수의 코어로 복잡한 명령어를 순차적으로 처리하며, GPU는 수천 개의 코어로 단순 연산을 동시 처리함.
- CUDA
    - 엔비디아에서 개발한 병렬 컴퓨팅 플랫폼 및 프로그래밍 모델. CPU가 순차적으로 처리하던 복잡한 연산을 GPU의 수많은 코어를 활용해 동시에 병렬 처리할 수 있게 해줌.
