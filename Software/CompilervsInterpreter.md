# CompilervsInterpreter
- 컴파일러
    - 사람이 읽기 쉬운 고급 프로그래밍 언어인 컴파일 언어로 작성된 소스 코드 전체를 컴퓨터가 직접 이해할 수 있는 저급 언어인 기계어나 어셈블리어 등으로 한 번에 번역하여 실행 파일을 만들어주는 소프트웨어 도구
    - 빠르지만 대신 유연성이 떨어짐
    - ex. C, C++
- 인터프리터
    - 프로그래밍 언어의 소스 코드를 미리 기계어로 번역(컴파일)하지 않고, 한 줄씩 직접 읽어가며 즉시 실행하는 컴퓨터 프로그램 또는 환경
    - 느리지만 유연성이 높음
    - ex. C#, Java, Python 등
- 다만 현대의 많은 프로그래밍 언어 중에는 컴파일과 인터프리터의 관계가 모호한 경우가 많아 컴파일러와 인터프리터를 칼로 자르듯이 나눌 수는 없음.
- 대부분의 프로그래밍 언어는 컴파일과 인터프리터 둘 다 가능.
