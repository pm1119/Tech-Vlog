# Process vs Thread
- [프로세스](Process.md)
- [스레드](Thread/Thread.md)
- 작동 방식
    - 운영체제는 프로세스마다 독립된 메모리 영역을 [코드/데이터/힙/스택](ProcessMemory.md) 형식으로 할당해 준다.
        - 이 경우, 각각의 독립된 메모리 영역을 할당하기 때문에 프로세스는 다른 프로세스의 변수나 자료에 접근이 불가능하다.
    - 하지만 스레드는 메모리를 서로 공유하는 것이 가능하다.
        - 이 경우, 프로세스가 할당받음 메모리 영역 내에서 스택 형식으로 할당된 메모리 영역은 따로 할당받고, 나머지 형식으로 할당된 메모리 영역을 갖게 된다.
    - 즉, 한 프로세스를 실행하다가 오류가 나서 강제로 종료했을 경우 공유하고 있는 파일을 손상시키는 경우가 아니라면 영향을 주지 않는다.
    - 반면 스레드의 경우, 스택을 제외한 나머지 형식의 메모리 영역을 몯 공유하기 때문에 한 스레드에서 오류가 발생한다면 같은 프로세스 내 모든 스레드가 강제 종료된다.
