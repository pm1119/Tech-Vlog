# ProcessMemory
- 운영체제가 프로그램 실행을 위해 할당하는 코드(Code), 데이터(Data), 힙(Heap), 스택(Stack) 4가지 주요 구조로 나뉨.
- 코드 영역
    - 실행할 프로그램의 명령어(바이너리 코드)가 저장되는 공간. CPU가 이 영역에서 명령어를 가져와 처리하며, 변경을 막기 위해 읽기 전용으로 설정되어 있음.
- 데이터 영역
    - 프로그램의 실행과 함께 할당되며, 프로그램이 종료될 때까지 유지되는 전역 변수와 정적 변수가 저장되는 공간
- 힙 영역
    - 프로그램 실행 중(런타임) 크기가 결정되는 동적 메모리 할당 영역으로, 프로그래머가 직접 메모리를 할당하고 해제하며, 객체나 동적 배열 등 크기가 유동적인 데이터, 즉 값을 저장하는 영역.
- 스택 영역
    - 함수 호출 시 생성되는 지역 변수, 매개변수, 반환 주소 등 임시 데이터를 저장하는 메모리 공간으로, 흔히 데이터가 저장되는 주소, 즉 참조를 저장하는 곳이라고도 함.
    - 이 영역에 함수 구역이 만들어짐
- 위에서부터 코드, 데이터, 힙, 스택 순으로 나눠지며, 안드로이드(IOS)의 경우 힙과 스택의 위치가 반대.
- 상술한 네 영역을 통틀어 유저가 접근할 수 있다 하여 유저 영역이라고도 부름.
- 메모리 할당
    - 자동 할당(값 형식)
        - 크기가 고정됨.
        - 스택 영역에 저장.
        - 주소는 컴파일 단계에서 결정
    - 동적 할당(참조 형식)
        - 크기는 가변형.
        - 변수에 new 키워드를 붙여 만들어짐.
        - 힙 영역에 클래스 구역이 저장되어 위치한 주소를 스택 영역에 위치한 변수가 참조하여 할당함.
        - 실행 상태(런타임) 단계에서 결정.
>값 형식 예시
```csharp
class Program
{
	class A
    {

    }

    private static void Main(string[] args)
	{
		A ob;
	}
}
```

>참조 형식 예시
```csharp
class Program
{
	class A
    {

    }

    private static void Main(string[] args)
	{
		A ob = new A();
	}
}
```
