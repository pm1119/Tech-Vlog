# Thread
- 프로그램 내에서 프로세스가 작업을 처리하는 실행 흐름의 최소 단위. 코드 실행을 담당함,
- 프로세스는 각자 고유한 메모리를 갖기에 프로세스 생성 시 필요한 정보를 복사해 줘야 하여, 상당량의 메모리를 중복해서 가지고 있어야 함.  생성과 제거가 느리고, 프로세스간 정보 교환도 어려움.
- 그래서 프로세스보다 작고 동시처리에 최적인 실행 단위가 필요하기에 만들어진 것이 스레드. 하나의 프로세스에 여러 개의 스레드가 있을 수 있고, 서로 메모리를 공유하여 코드를 실행함. 프로세스와 달리 생성과 제거가 빠르고, 적은 메모리를 점유하고, 정보 교환도 쉬움
- 스레드는 보통 여러 개로 실행하므로 여러 개의 스레드, 즉 멀티스레드라는 이름으로 부르며, 이러한 작업으로 수행하는 동작을 멀티스레딩이라 함.
