# Thread Control Block
- 운영체제가 각 스레드를 관리하기 위해 사용하는 데이터 구조.
- 스레드 ID, 스레드 상태, 프로그램 카운터를 포함한다.
- 운영체제는 이를 통해 스레드를 식별하고 실행 상태를 추적할 수 있음
- 주요 저장 정보
    - [스레드 식별자(TID)](ThreadId.md)
        - 스레드를 구분하는 고유 번호 
    - [스레드 상태](ThreadState.md)
        - 실행 중, 준비 중, 대기 중 등의 현재 상태
    - [프로그램 카운터(PC)](../../CPU/Register/Register.md)
        - 레지스터의 한 종류로, 스레드가 다음에 실행할 명령어 주소
    - 스택 포인터(SP)
        - 스레드 스택 영역의 위치를 가리키는 포인터
    - CPU 레지스터 값
        - 스레드가 멈췄을 때 다시 시작하기 위한 레지스터 상태
    - 프로세스 포인터
        - 이 스레드가 속한 부모 프로세스의 제어 블록(PCB)을 참조하는 것
