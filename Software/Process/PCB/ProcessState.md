# Process State
- 운영체제에서 실행 중인 프로그램의 생명 주기 단계. 총 5가지 상태로 구분됨.
- 상태 목록
    - 생성
        - 프로그램이 메모리에 적재되어 프로세스 제어 블록(PCB)을 할당받고 생성이 완료된 초기 단계. 준비 상태인 프로세스가 실행 상태로 전환되는 것을 디스패치라고 함.
    - 준비
        - CPU를 할당받아 실행할 준비가 완료되었으나, 자신의 차례가 아니어서 대기열(큐)에서 CPU를 기다리는 상태.
    - 실행
        -  프로세스가 CPU를 할당받아 실제로 명령어들을 수행하는 상태.
    - 대기
        - 입출력(I/O) 작업이나 특정 이벤트 발생을 기다리는 상태로, 완료될 때까지 CPU 사용을 멈추고 대기함.
    - 종료
        - 프로세스의 실행이 완전히 완료되어 할당된 메모리와 자원을 반납하고 PCB가 폐기된 상태.
