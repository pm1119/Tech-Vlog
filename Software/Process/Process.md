# Process
- 운영체제로부터 자원을 할당받은 작업의 단위.
- 하드 디스크 또는 SSD 등의 보조기억장치에 머물던 정적 상대(프로그램)가 메모리(RAM)에 올라와 CPU를 할당받고 실행 중인 동적 상태.
- 프로세스보다 더 작은 실행 단위를 [스레드](Thread.md)라고 부름.
- 옛날에는 하나의 프로세스만 실행할 수 있었으나 기술의 발전으로 CPU의 기능과 운영체제이 자원 관리 기능이 발전하면서 여러 개의 프로세스를 동시 실행하는 멀티태스킹이 가능해짐.
- 모든 프로세스는 부모-자식 관계를 가짐. A 프로세스가 B 프로세스를 생성할 경우 B 프로세스의 부모는 A 프로세스가 되는 것.
- 부모 프로세스가 자녀 프로세스보다 먼저 종료될 경우 남겨진 자녀 프로세스를 고아 프로세스라고 부른다. 리눅스 계열에선 이 경우 초기 프로세스(Init 프로세스)에게 고아 프로세스를 입양한다.
- 자녀 프로세스가 종료될 경우 부모 프로세스에서 종료된 자녀 프로세스의 메모리 값을 인수해야 메모리에서 제거되는데 그렇지 않아 계속 메모리 상에 남아있는 경우를 좀비 프로세스라고 부른다.
