# Garbage Collector
- 가비지 컬렉션 작업을 수행하는 주체(시스템 또는 프로그램 구성 요소). 
- 가비지 컬렉션
    - 프로그래밍 언어에서 메모리 관리를 자동화하는 기술. 프로그램이 동적으로 할당한 메모리 영역 중 더 이상 사용하지 않는 불필요한 메모리(Garbage)를 시스템이 주기적으로 찾아내어 자동으로 해제.
    - 핵심 개념 및 작동 방식
        - 추적 기반 가비지 컬렉션
            - 가장 대표적인 방식이며, 프로그램 실행 중 루트(Root, 항상 접근 가능한 시작점)에서부터 참조하는 객체들을 타고 들어가며 접근 가능 여부를 확인한다.
        - 마크 앤 스윕
            - Mark(표시)
                - 루트에서 출발해 도달할 수 있는 객체에 마킹을 한다.
            - Sweep(청소)
                - 마킹되지 않은 객체들을 메모리에서 제거한다.
        - Stop-the-World (STW)
            - 메모리를 안전하게 정리하기 위해 가비지 컬렉션이 작동하는 동안 프로그램의 실행을 잠시 멈추는 현상입니다
